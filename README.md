# Resuelve cualquier cubo de Rubik fácil
# DAM. Juan Manuel Ternero Pérez
- Índice
- Introducción: Enseñar a cualquiera a resolver cubos de rubik, mostrando el proceso de resolución de cada cubo. Mi objetivo es enseñar a cualquier persona a resolver un cubo de rubik centrándome en los cubos más convencionales. Soy un apasionado de los cubos de rubik y quiero compartirlo con todos los hispanohablantes.
- Funcionalidades y Tecnologías:
  -Funcionalidades: El usuario se autentica con nombre y contraseña. Si es un usario administrador, puede dar de alta a otros usuarios y gestinar distintos cubos. Si es un usuario no administrador, puede consultar los distitos cubos y apuntar los tiempos que tarda en resolver cada uno de ellos. 
  -Tecnologías MySQL Workbench, Java
- Guía de Instalación: Descargar la máquina virtual de Java(JRE), el .jar, instalar MySQL Workbench.
- Guía de Uso Administrador: Entrar en la aplicación como administrador, cambiar la contraseña, dar de alta usuarios, ver cubos existentes y dar de alta en caso de ser necesario.
- Guia de Uso No administrador: Entrar en la aplicación, cambiar la contraseña dada por defecto, ver cubos existentes y solicitar alta de cubos si quiere
